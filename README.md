# Telegram Bot Template

Готовый шаблон для быстрого старта Telegram-бота на TypeScript с простой настройкой под себя.

---

## Что внутри

**⚡ TypeScript + pnpm**
Строгая типизация с первого файла, быстрая установка зависимостей. Сборка одной командой: `pnpm start`.

**🔐 Авторизация администраторов**
Доступ к боту ограничен списком Telegram ID. Middleware проверяет каждый входящий запрос до того, как он дойдёт до обработчиков. Список задаётся в `.env` — не нужно лезть в код.

**🌍 Мультиязычность с сессиями**
Все тексты вынесены в единый файл переводов (`strings.ts`). Поддерживаются `ru` и `en` из коробки. Язык хранится в сессии каждого пользователя независимо — смена языка одним администратором не влияет на других.

**🌐 Прокси из коробки**
Поддержка HTTP/HTTPS прокси через переменную окружения `PROXY_URL`. Достаточно вписать URL — бот подхватит его при старте.

**📦 S3-хранилище**
Архитектура готова к подключению S3-совместимого хранилища (Garage, MinIO, AWS S3). Локальное хранилище легко заменяется облачным без изменения бизнес-логики.

**🔧 Безопасная работа с env**
Утилита `getEnv` с перегрузками: обязательные переменные бросают исключение при старте, опциональные возвращают `undefined`. Никаких молчаливых `undefined` в продакшне.

```bash

```
