# Управление списком администраторов

Доступ к боту ограничен списком Telegram ID. Все настройки хранятся в файле `.env` в корне проекта.

---

## Как узнать свой Telegram ID

Напиши боту [@userinfobot](https://t.me/userinfobot) — он ответит твоим ID. Это число вида `123456789`.

---

## Как добавить администратора

Открой файл `.env` и найди строку `ADMIN_IDS`. Добавь ID через запятую:

```
# Один администратор
ADMIN_IDS=123456789

# Несколько администраторов
ADMIN_IDS=123456789,987654321,555000111
```

Пробелы вокруг запятых допустимы — бот их игнорирует.

После изменения перезапусти бота.

---

## Как удалить администратора

Удали его ID из строки `ADMIN_IDS` в `.env` и перезапусти бота.

---

## Что видит неавторизованный пользователь

Бот ответит сообщением об отказе в доступе. ID пользователя в сообщении **не показывается** — чтобы узнать свой ID для добавления в список, воспользуйся [@userinfobot](https://t.me/userinfobot).
