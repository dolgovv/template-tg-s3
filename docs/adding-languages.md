# Тексты и языки

| Файл                        | Что в нём                                                    |
| --------------------------- | ------------------------------------------------------------ |
| `src/core/texts/en.ts`      | Встроенные английские тексты — эталон: ключи и параметры     |
| `src/core/texts/ru.ts`      | Встроенные русские тексты                                    |
| `src/app/texts/index.ts`    | **Ваши** тексты, изменения встроенных и новые языки          |

Ядро не правится: свои тексты пишутся в `src/app/texts/index.ts`, поэтому обновления шаблона приходят без конфликтов.

---

## Как устроен текст

Тексты — обычные данные: дерево разделов, в листьях строки.

```ts
files: {
  noImages: "В этой папке нет картинок",          // просто строка
  deleted: {
    file: "Файл {name} удалён",                     // {name} — параметр
    folder: "Папка {name} удалена",                 // род — отдельной фразой, не склейкой
  },
},
album: {
  uploaded: {                                       // текст по числу {count}
    one: "Загружен {count} файл",
    few: "Загружено {count} файла",
    many: "Загружено {count} файлов",
    other: "Загружено {count} файла",
  },
},
```

- **`{name}`** — параметр. Его значение экранируется, поэтому имя файла вроде `a<b>.txt` не сломает сообщение.
- **Объект с ключом `other`** — текст по числу. Форма выбирается по правилам языка (`Intl.PluralRules`): `zero`, `one`, `two`, `few`, `many`, `other`. Нужны только формы, которые есть в языке; недостающая берётся из `other`. Поэтому ключ `other` зарезервирован: так нельзя назвать раздел.
- **Остальное — HTML Telegram**: `<b>`, `<i>`, `<code>`, `<pre>`, `<a>`. Сам текст считается доверенным и не экранируется.
- Тексты в `commands` и `nav.outdated` — простой текст без HTML: первые идут в описания команд в `/help` и в подсказках Telegram, второй во всплывающее уведомление. Какие команды есть, решает код, а не этот раздел — см. [Как добавить новую команду](adding-commands.md).

## Свои тексты

Тексты для своего кода — в `customTexts`, на **языке по умолчанию** и все сразу. Они эталон для своих ключей и параметров, как `en.ts` для встроенных:

```ts
// src/app/texts/index.ts
export const customTexts = defineTexts({
  status: {
    ok: "Всё работает ✅",
    objects: "Объектов в бакете: {count}",
  },
});

type AppTexts = typeof customTexts;
declare module "../../core/index.js" {
  interface CustomTexts extends AppTexts {}
}
```

Объявление `declare module` уже есть в шаблоне: оно сообщает TypeScript, что у `ctx.t` появились `status.ok` и `status.objects({ count })`.
`customTexts` передаётся в `createBot` — в шаблонном `main.ts` это уже сделано. Если забыть, TypeScript не соберёт проект.

- `defineTexts` обязателен: без него строки теряют `{параметры}`, и сборка подскажет обернуть тексты.
- Имя раздела не может совпадать со встроенным (`nav`, `files`, `buttons`…) — ошибка при сборке и при запуске.
- Переводы — в `texts`, как и у встроенных. Непереведённое берётся из `customTexts`, в лог пишется, сколько не хватает:

```ts
export const texts: TextsOverrides = {
  en: { status: { ok: "All good ✅" } },   // objects возьмётся из customTexts
};
```

## Изменить встроенный текст

Достаточно указать только то, что меняется:

```ts
// src/app/texts/index.ts
export const texts: TextsOverrides = {
  ru: {
    nav: { empty: "Здесь пока ничего нет" },
    common: { greet: "Здравствуйте, {name}! Это админка {site}" },
  },
};
```

Остальные тексты останутся встроенными.

## Добавить язык

```ts
export const texts: TextsOverrides = {
  de: {
    meta: { name: "Deutsch" },                     // надпись на кнопке языка
    nav: { empty: "Dieser Ordner ist leer" },
    files: { deleted: { file: "Datei {name} gelöscht", folder: "Ordner {name} gelöscht" } },
    // ...
  },
};
```

Больше ничего не нужно: кнопка «Deutsch» появится в главном меню, а нажатие `lang=de` заработает само.
Список языков строится из текстов. Непереведённое берётся из языка по умолчанию, а в лог при старте пишется, сколько текстов не хватает.

Полный список встроенных ключей — в `src/core/texts/en.ts`, своих — в `customTexts`.

## Проверки

**При сборке (TypeScript):**

- в `ru.ts` и других встроенных языках есть все ключи `en.ts`;
- `customTexts` передан в `createBot`, обёрнут в `defineTexts` и не занимает встроенные разделы;
- в `texts` нет неизвестных ключей, в том числе своих;
- в коде `ctx.t.files.deleted.file({ name })` нельзя опечататься ни в ключе, ни в параметре, ни забыть `count` у текста по числу.

**При старте бота (предупреждение в логе):**

- неизвестный ключ, например `nav.emtpy`, — игнорируется;
- параметр, которого нет в английском тексте, например `{nme}`, или не строка вместо строки — используется встроенный текст;
- непереведённые тексты нового языка — используются тексты языка по умолчанию.

Бот при этом запускается: ошибка в тексте не должна ронять админку.

## Язык по умолчанию

Задаётся в `src/app/main.ts`:

```ts
const app = createBot({ ...config.bot, defaultLang: "ru", texts });
```

С него начинают новые пользователи, и из него берутся непереведённые тексты других языков.
Уже существующие сессии не изменятся: язык хранится в файлах сессий в папке `sessions/`.
Если язык из сессии убрали из текстов, пользователь получит язык по умолчанию.

## Тексты в коде

`ctx.t` — тексты на языке пользователя. Текст без параметров — строка, с параметрами — функция:

```ts
ctx.t.nav.empty;                                   // "Папка пуста"
ctx.t.files.deleted[isFile ? "file" : "folder"]({ name });
ctx.t.album.uploaded({ count: names.length });
```

Если в параметр нужно передать готовый HTML, оберните его в `raw()` — тогда он не экранируется. Список значений — `list(names)`: каждое экранируется, затем они соединяются через запятую.

```ts
import { list, raw } from "../core/index.js";

ctx.t.album.failed({ names: list(failed) });
ctx.t.album.failed({ names: raw("<code>" + escapeHtml(name) + "</code>") });
```
