# Как добавить новую команду

Своя команда — это три шага в `src/app/`: текст, команда, ответ. Ядро (`src/core/`) не правится, поэтому обновления шаблона приходят без конфликтов.

| Файл                     | Что в нём                                   |
| ------------------------ | ------------------------------------------- |
| `src/app/texts/index.ts` | Ваши тексты и их переводы                   |
| `src/app/main.ts`        | Команды, ответы на вопросы, главное меню    |

---

## Шаг 1 — Текст

Свои тексты пишутся в `customTexts` на **языке по умолчанию** (`defaultLang`), все сразу. По ним TypeScript проверяет каждый вызов `ctx.t`: опечатка в ключе или параметре не соберётся.

```ts
// src/app/texts/index.ts
export const customTexts = defineTexts({
  status: {
    command: "состояние бота",                        // описание для /help и подсказок
    ok: "Всё работает ✅, {name}",                     // {name} — параметр
    objects: {                                         // текст по числу {count}
      one: "{count} объект",
      few: "{count} объекта",
      many: "{count} объектов",
      other: "{count} объекта",
    },
    refresh: "🔄 Обновить",                            // надпись на кнопке
  },
});
```

- `defineTexts` обязателен: без него TypeScript не видит `{параметры}`, и сборка подскажет, что не так.
- Имя раздела — любое, кроме встроенных (`nav`, `files`, `buttons`…).
- Переводы — в `texts` того же файла, только то, что переведено. Непереведённое берётся из языка по умолчанию:

```ts
export const texts: TextsOverrides = {
  en: { status: { command: "bot status", ok: "All good ✅, {name}" } },
};
```

Подробнее о параметрах, текстах по числу и HTML — в [Тексты и языки](adding-languages.md).

## Шаг 2 — Команда

```ts
// src/app/main.ts
app.command("status", (t) => t.status.command, async (ctx) => {
  await ctx.ui.text(ctx.t.status.ok({ name: ctx.from?.first_name ?? "" }));
});
```

- Второй аргумент — описание на языке пользователя. Из него строятся `/help` и подсказки Telegram при вводе `/`.
- `undefined` вместо описания — команда работает, но нигде не показывается.
- Имя — латиница в нижнем регистре, цифры и `_`, до 32 символов. Занятое имя (`start`, `help`, `nav`…) — ошибка при запуске.
- Место в `main.ts` не важно: до или после `app.use(fileManager(...))` команда сработает. Порядок в `/help` — порядок добавления, `/help` всегда последняя.

## Шаг 3 — Ответ: `ctx.ui`

Все тексты — HTML: берите их из `ctx.t`, там параметры экранируются сами.

| Метод                                   | Что делает                                                      |
| --------------------------------------- | --------------------------------------------------------------- |
| `ctx.ui.text(text, buttons?)`           | Новое сообщение                                                 |
| `ctx.ui.menu(text, buttons?)`           | Меню: правит то же сообщение на месте, новое — если его нет     |
| `ctx.ui.edit(text, buttons?)`           | Заменяет сообщение, на кнопке которого нажали                   |
| `ctx.ui.ask(text, id, buttons?)`        | Вопрос: следующий текст пользователя уйдёт в `app.onAnswer(id)` |
| `ctx.ui.photo(photo, { caption, buttons })` | Фото                                                        |
| `ctx.ui.album(photos, { caption })`     | Фото альбомами по 10, подпись под первым. Пустой массив — ничего |
| `ctx.ui.document(file, { name, caption, buttons })` | Файл                                                |
| `ctx.ui.audio(...)`, `ctx.ui.video(...)` | То же с плеером Telegram                                       |

Фото и файл — это `Buffer`, `InputFile` из grammY, `file_id` или URL. Для `Buffer` имя задаётся в `name`.

Кнопки — массив рядов, о них в [Добавление кнопок](adding-inline-buttons.md):

```ts
await ctx.ui.text(ctx.t.status.objects({ count: 3 }), [
  [{ text: ctx.t.status.refresh, call: "status_refresh" }],
]);
```

## Вопрос и ответ

`ctx.ui.ask` задаёт вопрос, а следующий текст пользователя приходит в обработчик с тем же `id`:

```ts
app.command("rename_site", (t) => t.site.command, (ctx) =>
  ctx.ui.ask(ctx.t.site.askName, "site_name"),
);

app.onAnswer("site_name", async (ctx, text) => {
  if (text.length < 3) return ctx.ui.ask(ctx.t.site.tooShort, "site_name"); // спросить ещё раз
  await ctx.ui.text(ctx.t.site.renamed({ name: text }));
});
```

- Любая команда или нажатие кнопки снимает вопрос: пользователь ушёл в другое место.
- Файл, фото или стикер вопрос не снимают — ждём текст.
- Вопрос без `app.onAnswer` с таким `id` — ошибка в логе, пользователь получит общее сообщение об ошибке.

## Подсказки Telegram

При запуске (`app.start()`) бот отправляет список команд в Telegram: отдельно для каждого языка из текстов и общий — на языке по умолчанию.
Telegram выбирает список по языку **приложения** пользователя, а не по языку, выбранному в боте.
Язык с кодом не из двух букв (например, `pt-br`) подсказок не получает, в лог пишется предупреждение.

## Частые вопросы

**Что будет, если забыть текст?**
Ключ, которого нет в `customTexts`, не соберётся. Непереведённый текст другого языка возьмётся из языка по умолчанию, а в лог при старте придёт предупреждение.

**Нужно ли экранировать параметры?**
Нет. Значения `{параметров}` экранируются сами. Готовый HTML передавайте через `raw()`.

**Можно ли использовать grammY напрямую?**
Да, `app.bot` — обычный бот [grammY](https://grammy.dev). Обработчики текста (`app.bot.on("message:text")`, `app.bot.hears`) ставьте **до** `app.use(fileManager(...))`: на любой нераспознанный текст файловый менеджер отвечает справкой. Обработчикам кнопок и команд место не важно.
