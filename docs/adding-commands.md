# Как добавить новый ответ на команду бота

Этот гайд для тех, кто хочет добавить новую команду боту, не разбираясь глубоко в коде.
Весь процесс состоит из трёх шагов и затрагивает только три файла.

---

## Файлы, с которыми предстоит работать

| Файл                | Что в нём                                 |
| ------------------- | ----------------------------------------- |
| `translates.ts`     | Тексты и кнопки для каждого языка         |
| `DialogEngine.ts`   | Сборка готового ответа из текста и кнопок |
| `CommandHandler.ts` | Регистрация команды и вызов ответа        |

---

## Шаг 1 - Добавить текст в `translates.ts`

Открой файл `translates.ts`. Там два объекта: `textTranslates` (тексты) и `menusTranslates` (кнопки).

### Добавить текст

В `textTranslates` добавь новую строку в каждый язык (`ru`, `en` и другие, если есть).
Ключ - это внутреннее название, по нему потом обращаются в коде.

```ts
// было
ru: {
  help: "Здесь будет /help текст.",
  // ...
}

// стало - добавили ключ "status"
ru: {
  help: "Здесь будет /help текст.",
  status: "Всё работает нормально ✅",
  // ...
}
```

Не забудь добавить тот же ключ в английский раздел:

```ts
en: {
  help: "Here will be /help text.",
  status: "Everything is working fine ✅",
  // ...
}
```

### Добавить кнопки (необязательно)

Если под сообщением нужны кнопки - добавь их в `menusTranslates` с тем же ключом.
Каждая кнопка - это объект с двумя полями:

- `text` - надпись на кнопке, которую видит пользователь
- `call` - внутренний идентификатор нажатия (латиница, без пробелов)

```ts
// в menusTranslates → ru
ru: {
  help: [],
  status: [
    { text: "Обновить", call: "status_refresh" },
    { text: "Подробнее", call: "status_details" },
  ],
  // ...
}
```

Если кнопки не нужны - оставь пустой массив `[]`. Бот сам не добавит кнопки к сообщению.

---

## Шаг 2 - Добавить сборку ответа в `DialogEngine.ts`

Открой `DialogEngine.ts`. Там уже есть примеры - `buildHelp`, `buildWelcome` и другие.
Добавь новый метод по той же схеме:

```ts
buildStatus(): BotMessage {
  const t = textTranslates[this.lang];
  const m = menusTranslates[this.lang] ?? {};
  return this.factory.text(t.status, m.status);
}
```

Метод берёт текст и кнопки для текущего языка и собирает из них готовое сообщение.

---

## Шаг 3 - Зарегистрировать команду в `CommandHandler.ts`

Открой `CommandHandler.ts`. В конструкторе зарегистрируй новую команду:

```ts
this.bot.command("status", (ctx) => {
  this.onStatus(ctx);
});
```

Затем добавь метод-обработчик:

```ts
onStatus(ctx: Context) {
  if (ctx.chat) {
    const reply = this.dialog.buildStatus();
    this.resolver.reply(ctx, reply);
  }
}
```

Готово. После перезапуска бота команда `/status` будет работать.

---

## Итого - что нужно сделать для новой команды `/status`

1. **`translates.ts`** - добавить ключ `status` с текстом в `textTranslates` (для каждого языка) и массив кнопок в `menusTranslates` (можно пустой `[]`)
2. **`DialogEngine.ts`** - добавить метод `buildStatus()`
3. **`CommandHandler.ts`** - зарегистрировать `bot.command("status", ...)` и добавить метод `onStatus()`

## Частые вопросы

**Можно ли добавить кнопки позже, не меняя остальной код?**
Да. Просто заполни пустой массив `[]` в `menusTranslates` - кнопки появятся автоматически без изменений в `DialogEngine` или `CommandHandler`.

**Что будет, если забыть добавить ключ в один из языков?**
TypeScript подсветит ошибку при сборке - все языки должны иметь одинаковый набор ключей.

**Как называть `call` у кнопок?**
Любая строка без пробелов, латиницей. Рекомендуется формат `команда_действие`, например `status_refresh`. Это значение приходит в обработчик нажатия кнопки.
